# Herbal-Care-Point
A modern herbal healthcare and e-commerce platform built with PHP, offering natural wellness products, secure online ordering, QR-based verification, and smart order tracking.

**📌 About the Project**
Herbal Care Point is a responsive herbal product management and online shopping platform that provides users with a seamless experience for browsing, purchasing, and tracking herbal healthcare products. The application features secure authentication, order tracking, QR verification, shopping cart functionality, and a premium modern interface.

Built for simplicity, performance, and smooth user experience.
